## Decision

The existing Research-to-WIC provenance boundary satisfies the WIC-011
acceptance for source attribution and the current code has no direct trade
effect. Do not add a live Finance dependency in this audit: the Finance module
does not yet provide a verified, read-only watchlist signal source. When that
producer exists, the smallest safe integration is an adapter from its typed,
consent-scoped read-only envelope to WIC source-backed findings, preserving the
source reference, observation time and uncertainty. It must not import or
write Finance storage and must not expose a trade/action callback.
