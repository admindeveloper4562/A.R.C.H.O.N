# WIC-014 — Live-feed transparency and user-acceptance audit

**Status:** audited against integration base `97b9d60310e1a10f10c90a6f7461aa7211766e2f`.

**Parent:** WIC-014 — Conduct live feed transparency/user acceptance review

**Acceptance:** Data ages and alerts accurate for tested current cases.

## Evidence inventory

| Area | Pinned evidence | Finding |
| --- | --- | --- |
| Source observations | `src/jarvis_v2/wic/__init__.py`, `SourceObservation`, `SourceStore` | Observations retain source/feed/article URLs, fetched time, optional published time and source-updated time. Replay is immutable and idempotent. |
| Source health | `SourceStore.record_health` and `SourceStore.health` | Health is explicit as `fresh`, `stale`, `outage` or `unknown`. A successful snapshot becomes stale after the bounded threshold; an outage preserves the last successful timestamp. |
| Feed boundary | `PublicSourceIngestion.ingest` | Only allowlisted public policies are accepted. The transport is injected and bounded; unavailable, timeout and invalid-provider states are recorded without exposing provider details. |
| Alert policy | `AlertPolicy`, `AlertStore` | Policies are owner-scoped and validate topics, cadence, timezone and quiet hours. Material changes are deduplicated and cadence/quiet-hour suppression is explicit. |
| Alert delivery | `AlertStore.evaluate` | WIC records an alert admission decision only. No notification transport or external side effect is implemented in this checkout. |
| Truthfulness boundary | `CitedSummaryComposer`, `ClaimLedger`, `WorldCard` | Citations, independent dates, corroboration, corrections and retractions remain visible. Unsupported `live` summary freshness is rejected. |

The inspected source was unchanged before this report was written. No
credentials, private data or raw provider content were read. The current
implementation uses an injected feed transport for deterministic testing; no
live network feed was treated as evidence.

## Decision

The reviewed WIC implementation satisfies the tested local transparency and
alert semantics. It does **not** claim live-feed or user-acceptance evidence:
that requires an authorized real source and a separately recorded current-case
review. Keep that limitation visible for release readiness; do not replace it
with mocked network evidence.
