   `tests/test_server.py`: 82 tests executed, with one failure and one error.
   The error was the legacy default database reporting schema 10 newer than
   the pinned source's supported schema 8. The failure expected the temporary
   archive to appear as the owner-selected real checkout. These are recorded
   failures, not passes or evidence to ignore.
2. The ARCHON Runtime source inventory found only the package marker and no
   server, router, voice, web, or desktop implementation to expose as a dead
   demo route.
3. No legacy file was copied, executed on the host as an application service,
   or changed by this candidate.
4. The audit worktree contains only this Markdown change. The legacy checkout,
   canonical SQLite state, integration worktree, and protected branches were
   not modified.
